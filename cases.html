2018 · CVE-2017-5753

Spectre V1 · Bounds Check Bypass

A conditional check eventually fails, but its predicted pass path may already have used an out-of-bounds value.

Trigger
Unresolved conditional branch
Value / prediction source
Victim-accessible array data
Architectural outcome
Reject x = 16 when size = 16

V1 predicts a direction. V2 predicts an indirect target. Neither example requires the load-permission failure central to classic Meltdown.

Trigger

Value / prediction source
Victim code at predicted gadget

2018 · CVE-2017-5754

Meltdown V3 · Rogue Data Cache Load

A load still faults, but affected hardware may already have forwarded the protected byte to dependent transient instructions.

Trigger
Load lacks user permission
Value / prediction source
Data behind a protected mapping
Architectural outcome
Permission page fault; no byte committed

The later timing measurement is ordinary observation code, not execution resuming at the original next instruction after the fault handler. The transient byte is never a permitted architectural read.

2018 · CVE-2018-3615 / CVE-2018-3620 / CVE-2018-3646

Foreshadow / L1 Terminal Fault

Translation fails, yet data associated with the invalid entry may be transiently supplied from L1D.

Trigger
Terminal address-translation fault
Value / prediction source
Relevant data already in L1D
Architectural outcome
Page fault; no valid translation

L1TF selects through invalid translation and L1D residency. MDS samples internal buffers and generally cannot choose a secret address in this way.

MDS · RIDL / ZombieLoad / Fallout

A transient sample may come from a CPU buffer, not from the address the load requested.

Trigger
Faulting or assisting load
Value / prediction source
Fill / store buffers or load ports
Architectural outcome
Correct retry result or a fault

MDS describes the observer sampling a value. LVI describes a victim consuming a wrong operand. SSB can expose an old value from the same logical location, rather than MDS’s unrelated sample.

2020 · CVE-2020-0551

LVI · Load Value Injection

The victim’s own dependent instructions may briefly use a value that its load should not have supplied.

Trigger
Victim load faults / assists / aborts
Value / prediction source
Wrong operand in victim dataflow
Architectural outcome
No result based on wrong operand

Reverse the MDS viewpoint: the important event is a victim consuming the wrong value, not merely the observer reading a leftover sample.

2018 · CVE-2018-3639

SSB · Spectre V4

A later load may temporarily read OLD before an earlier overlapping store’s address is resolved.

Trigger
Unresolved earlier store address
Value / prediction source
Old value of the same location
Architectural outcome
Respect store → load dependency

The stale 3 belongs to slot_A. MDS’s illustrative 0x6D came from unrelated buffer activity; the two meanings of “old data” must not be merged.

2019 · CVE-2019-11135

TAA · TSX Asynchronous Abort

Transaction rollback can preserve architectural correctness while a pending abort opens a buffer-sampling window.

Trigger
TSX asynchronous abort pending
Value / prediction source
Internal buffer sample
Architectural outcome
Abort transaction; roll back its writes

MDS and TAA can involve similar data sources, but the pending transaction-abort window distinguishes TAA. A victim’s lack of transactions does not eliminate this sampling path.

2022 · CVE-2022-0001

BHI · Branch History Injection

Changing branch-history context can change which learned target is predicted, without changing the real target.

Trigger
History-sensitive indirect prediction
Value / prediction source
History selects a target candidate
Architectural outcome
Resolve and execute NORMAL

Classic BTI focuses on influenced target prediction; BHI highlights the history used to choose a target. Both belong to the Spectre-V2 family and still require a useful disclosure path.

2022 · CVE-2022-29900 / CVE-2022-29901

Retbleed · Return Target Prediction

A RET can transiently go to a wrong target even though the saved architectural return address was never changed.

Trigger
RET under affected prediction conditions
Value / prediction source
Return-target predictor state
Architectural outcome
Return to saved R_OK

A prediction problem is not a stack overwrite or ROP modification of the architectural return address. BHI focuses on history selection; Retbleed focuses on the return instruction’s prediction path.

2023 · CVE-2022-40982

Downfall · Gather Data Sampling

An affected transient gather may forward stale vector data; the victim need only have used vector registers.

Trigger
Transient gather encounters a fault
Value / prediction source
Stale vector-related state
Architectural outcome
Apply gather completion/fault rules

GDS concerns a gather-related sampling path. RFDS concerns other stale register-file states. Neither means the victim must run the observer’s trigger instruction.

2024 · CVE-2023-28746

RFDS · Register File Data Sampling

Previously used register-file values may be sampled; this is not reading another task’s current named register.

Trigger
Affected register-file sampling condition
Value / prediction source
Old register-file entries
Architectural outcome
Use current architectural register state

RFDS is not another name for GDS, and “stale register value” does not imply an architectural permission to read another task’s register file.

2023 · CVE-2023-20569

Inception / SRSO

Speculation can train later return predictions, so recovering from one wrong path does not remove the predictor state it created.

Trigger
Phantom speculation and return prediction
Value / prediction source
Predictor state trained transiently
Architectural outcome
Real return address remains R_OK

Retbleed also concerns RET prediction, but Inception highlights phantom speculation and transient training of later predictions. Neither requires rewriting the software return address.

2023 · CVE-2023-20593

Zenbleed · Register Lifetime / Recovery

On affected Zen 2 cores, a vector-register recovery bug can expose stale data architecturally, without a cache-timing receiver.

Trigger
Affected speculative register recovery
Value / prediction source
Reused physical vector-register data
Architectural outcome
Restore this context’s valid register state

This is the taxonomy exception: a speculative precursor can lead to an architecturally visible stale-register value. The other sampling models discard their transient sample as an architectural result.

03 / HOW TO READ

When reading a new advisory, look beyond the CVE

Record in this order: Triggering conditions → Data sources → Trust boundaries → Actual attacker capabilities → Official mitigations → Residual conditions.

EVIDENCE

Research PoC

Answer "whether it is observable under certain conditions". Its performance, success rate, and target devices cannot be automatically extrapolated to all platforms.

APPLICABILITY

Vendor advisory

Identification of affected products and supported microcode/firmware. The same vulnerability name may have different conclusions in different generations.

DEPLOYMENT

System documentation

Confirms the actual enabled mitigation and visibility status of the current kernel. Cloud virtual machines also depend on the host layer.
