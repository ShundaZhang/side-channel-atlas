02 / CASE FILES

九个值得精读的案例

过滤机制，再打开论文、公告和原作者 PoC。PoC 链接指向源代码或研究页，并非本站执行按钮。

2018 · PREDICTION · CVE-2017-5753

Spectre V1 · Bounds Check Bypass

错误预测边界检查，使同一地址空间的受害者代码瞬态访问越界数据，再经缓存通道观察。关键在具体 gadget 和可控输入，不是“任意机器码都可越权”。

复现前提：目标编译结果、训练窗口、测量环境与防护都会影响演示。

把执行窗口与读出通道分开看。边界操作数迟到时，错路径的加载可能先执行；第二次加载用瞬态值索引探针，把第一次加载的数据变成可计时的缓存行。缓解要阻止或约束相关的依赖访问。

原始论文 ↗MIT 教学实验 ↗
2018 · PREDICTION · CVE-2017-5715

Spectre V2 · Branch Target Injection

攻击者影响间接分支目标预测，受害者瞬态执行有泄漏能力的代码片段。读防御时区分用户 / 内核、进程之间及虚拟机边界。

复现前提：预测器与缓解机制高度依赖 CPU、微码和系统版本。

分别定位间接分支、预测目标和泄漏 gadget。最终架构目标仍可正确，另一个 gadget 却可能瞬态执行。内核入口、客体入口与 SMT 共享分别涉及不同的预测器控制。

原始论文 ↗Linux 缓解文档 ↗
2018 · FAULT · CVE-2017-5754

Meltdown V3 · Rogue Data Cache Load

部分受影响处理器在权限故障被处理前，瞬态链可使用受保护数据。它与训练受害者分支的 Spectre 机制不同，KPTI 是历史上重要的操作系统应对之一。

复现前提：旧硬件和旧配置；更新后的主机上 PoC 失败很常见。

在受影响硬件上，加载仅主管可访问的映射时，故障在架构上生效之前，读出的值可能已可供瞬态依赖使用。KPTI 从用户态页表视图移除大多数内核映射，改变该机制能够到达的地址范围。

原始论文 ↗研究 PoC ↗
2018 · FAULT · L1TF

Foreshadow / L1 Terminal Fault

终止页表项触发的故障与 L1D 数据交互，可影响 SGX、系统管理及虚拟化边界。不同场景对应不同 CVE；不要只用“L1TF”推断目标环境风险。

复现前提：处理器、页表场景、宿主 / 客体配置。

触发终止故障的 PTE 中，物理地址位可能被瞬态使用；可取到的数据受 L1D 已驻留内容限制。清理 PTE 地址位和在相关 VM 切换处刷新 L1D，分别针对攻击链的不同环节。

2019 · SAMPLING · MDS

RIDL / ZombieLoad / Fallout

从填充缓冲区、载入端口或存储缓冲区采样旧数据。与原始 Meltdown 不同，攻击者通常不能指定一个任意目标地址；同核、SMT 与后处理至关重要。

复现前提：特定 Intel CPU、缓冲区行为、微码与内核状态。

用结构来区分变体。填充缓冲区跟踪在途缓存行填充，存储缓冲区保留待写数据，加载端口负责加载数据路径。原始样本可能混有无关活动，数据恢复率与能否归因到受害者应分别测量。

2022 · PREDICTION · BHI

Branch History Injection

分支历史可影响后续间接目标选择，即使已有一些跨特权预测器隔离。分析时要看具体受害者 gadget、内核构建和后续缓解。

复现前提：模型、系统版本与可触发代码路径。

BHI 通过分支历史影响间接目标选择。读公告时核对目标 CPU 如何结合历史与目标预测，以及内核在哪些入口清理或限制历史。它提供瞬态控制流引导，仍需可用的泄漏 gadget 和接收端。

2023 · SAMPLING · CVE-2022-40982

Downfall / Gather Data Sampling

在部分 Intel 处理器上，瞬态 gather 可采样先前的向量数据。它是数据采样问题，不等同于目标程序必须调用 gather。

复现前提：受影响型号、微码、向量指令和同核 / 同线程条件。

Gather 将多个地址的数据聚合到向量各 lane。受影响硬件上，攻击者发起的瞬态 gather 可能取得先前活动的残留向量数据。应核对采样行为和向量使用的隔离边界，包括适用时的同核兄弟线程。

2023 · PREDICTION · CVE-2023-20569

Inception / SRSO

返回地址预测受到操控，可能把执行引向瞬态泄漏片段。AMD 公告强调利用条件与产品代际差异；缓解涉及微码与操作系统配置。

复现前提：受影响 AMD 型号及正确的返回预测条件。

Inception 论文区分 Phantom speculation 与瞬态训练：预测产生的控制流效应可为后续返回误预测埋下状态。需看具体 CPU 的缓解路径，不能仅凭普通分支历史清理判断返回预测是否受到保护。

2023 · REGISTER LEAK · CVE-2023-20593

Zenbleed · 跨进程寄存器残留

Zen 2 特定微架构条件下，YMM 寄存器可能保留其他进程 / 线程敏感信息。它与“训练分支→缓存编码”的经典 Spectre 链不同，适合作为分类边界案例。

复现前提：Zen 2、特定指令条件及修复状态。

在受影响的 Zen 2 核心上，原报告将推测 VZEROUPPER 与回滚问题追溯到物理向量寄存器的生命周期。VZEROUPPER 在逻辑上清零高半部；错误恢复可能使寄存器文件中的残留内容在架构上可读。这些寄存器内容的读出不需要缓存计时接收端。

03 / HOW TO READ

读一份新公告时，
别只抄 CVE

按这个顺序记录：触发条件 → 数据来源 → 信任边界 → 实际攻击者能力 → 官方缓解 → 残余条件。

EVIDENCE

研究 PoC

回答“某条件下是否可观察”。其性能、成功率、目标设备不能自动外推到所有平台。

APPLICABILITY

供应商公告

确认受影响产品与支持的微码 / 固件。相同漏洞名称在不同代际上可能有不同结论。

DEPLOYMENT

系统文档

确认当前内核实际启用的缓解和可见状态。云虚拟机还要看宿主层。
