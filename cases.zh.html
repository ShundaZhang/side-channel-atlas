Foreshadow / L1 Terminal Fault

地址翻译失败，但与无效页表项相关的数据可能仍从 L1D 被瞬态提供。

L1TF 的核心约束是无效翻译与 L1D 驻留。MDS 面向内部缓冲区采样，通常不能以同样方式指定秘密地址。

TAA · TSX Asynchronous Abort

事务回滚维持了架构正确性，待处理的异步中止却可能打开缓冲区采样窗口。

BHI · Branch History Injection

分支历史上下文变化，可能改变选中的已学习预测目标，而真实目标不变。

Retbleed · Return Target Prediction

即使保存的正式返回地址未被改写，RET 仍可能短暂走向错误预测目标。

触发
RET 处于受影响预测条件
值 / 预测来源

正式结果

预测问题不是栈覆盖，也不是用 ROP 改写正式返回地址。BHI 关注历史选择，Retbleed 关注返回指令进入哪种预测路径。

Inception / SRSO

Retbleed 同样涉及 RET 预测，Inception 则突出 Phantom 推测与对后续预测的瞬态训练。二者都不要求改写软件保存的返回地址。

03 / HOW TO READ

读一份新公告时，
别只抄 CVE

按这个顺序记录：触发条件 → 数据来源 → 信任边界 → 实际攻击者能力 → 官方缓解 → 残余条件。

EVIDENCE

研究 PoC

回答“某条件下是否可观察”。其性能、成功率、目标设备不能自动外推到所有平台。

APPLICABILITY

供应商公告

确认受影响产品与支持的微码 / 固件。相同漏洞名称在不同代际上可能有不同结论。

DEPLOYMENT

系统文档

确认当前内核实际启用的缓解和可见状态。云虚拟机还要看宿主层。
